# Stream Labs — Quotation Tool

Локальное веб-приложение для пресейла: сборка конфигурации серверов, расчёт хранилища и RAID, коммерческие предложения (КП) по прайс-листу, экспорт в Excel / PDF, связь с Pipedrive и Jira.

Подробная инструкция для пользователей — `docs/Quotation_Tool_User_Guide.docx`.

## Быстрый старт (Windows)

1. Установи **Python 3** ([python.org](https://www.python.org/downloads/)), отметив **"Add Python to PATH"**.
2. Дважды кликни **`start.bat`**:
   - при первом запуске ставятся Flask, openpyxl и Pillow;
   - делается резервная копия `data/*.json` в `data/backup/ГГГГ-ММ-ДД/` (хранятся последние 30 дней);
   - браузер открывается на `http://localhost:5000` (если порт занят — на следующем свободном до 5019).
3. Остановка — закрыть окно командной строки или `Ctrl+C`.

Для интеграций скопируй `data/config.example.json` в `data/config.json` и впиши токены Pipedrive / Jira. `config.json` в git не попадает.

## Вкладки

| Вкладка | Назначение |
|---|---|
| Configurator | Сборка конфигурации сервера из каталога компонентов, задача в Jira для закупок |
| Component Catalog | Редактирование каталога компонентов (`data/catalog.json`) |
| RAID Calculator | Полезный объём массива по уровню RAID и дискам |
| Storage Calculator | Объём записи: группы сервисов × битрейт × дни хранения + запас; результат передаётся в RAID Calculator |
| Quotation | КП: клиент, сделка Pipedrive, позиции прайса, предпросмотр, экспорт |
| Pricelist | Прайс-лист продуктов (`data/pricelist.json`), загрузка из xlsx, логотипы продуктов |
| Saved | Сохранённые КП по номеру сделки и версии (V1, V2, …) |
| Server Calculator | Оценка сервера MultiProbe по параметрам сигналов (разрешение, кодек, битрейт) на основе внутренних нагрузочных тестов |

## Экспорт

- **Excel** — `export/generate_xlsx.py`, файл называется `<Компания>_<PP-номер>_<версия>.xlsx`.
- **PDF** — через предпросмотр: кнопка Preview открывает документ в браузере, дальше `Ctrl+P` → «Сохранить как PDF». HTML строит `export/generate_pdf.py`.
- Готовый файл можно прикрепить к сделке в Pipedrive и обновить сумму сделки.

## Структура проекта

```
quotation-tool/
├── server.py             # Flask-сервер и API (точка входа)
├── database.py           # SQLite: снимки КП по deal_id + версии
├── pipedrive.py          # Pipedrive: сделка, сумма, прикрепление файла
├── jira_integration.py   # Jira: создание задачи для отдела закупок
├── start.bat             # Запуск одним двойным кликом
├── export/
│   ├── generate_xlsx.py  # Экспорт КП в Excel
│   ├── generate_pdf.py   # HTML для предпросмотра / печати в PDF
│   └── tmp/              # Сгенерированные файлы (не в git)
├── data/
│   ├── catalog.json      # Каталог компонентов серверов
│   ├── pricelist.json    # Прайс-лист продуктов
│   ├── companies.json    # Компании-продавцы (реквизиты, логотип, активная)
│   ├── contacts.json     # Контакты
│   ├── signers.json      # Подписанты КП
│   ├── config.json       # Токены и настройки интеграций (не в git)
│   ├── quotations.db     # Сохранённые КП (не в git)
│   ├── backup/           # Ежедневные копии JSON (не в git)
│   └── assets/           # Логотипы компаний и продуктов
├── static/app.js         # Логика интерфейса
├── templates/index.html  # Главная страница
└── docs/                 # Инструкция пользователя
```

## Доступ для коллег (локальная сеть)

Сервер слушает все сетевые интерфейсы, поэтому коллеги могут открыть `http://<IP-машины>:5000` (IP — через `ipconfig` → IPv4 Address). Авторизации нет: любой в сети может менять прайс, контакты и КП, поэтому не открывай доступ за пределы офисной сети.
