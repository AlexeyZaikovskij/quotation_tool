# Stream Labs — Server Configurator

Инструмент для сборки конфигурации серверов и формирования спецификации для Jira / отдела закупок.

## Быстрый старт (Windows)

1. Убедись, что установлен **Python 3** ([python.org](https://www.python.org/downloads/))
   - При установке обязательно отметь галочку **"Add Python to PATH"**
2. Дважды кликни **`start.bat`**
   - При первом запуске автоматически установится Flask
   - Браузер откроется на `http://localhost:5000`
3. Для остановки — закрой окно командной строки или нажми `Ctrl+C`

## Каталог компонентов

Каталог хранится в `data/catalog.json` и редактируется прямо в интерфейсе (вкладка **Component Catalog**):
- Переименовать компонент — иконка карандаша
- Удалить компонент — иконка корзины
- Добавить компонент — поле внизу списка
- Добавить категорию — кнопка «+» в шапке списка категорий
- Все изменения сохраняются сразу в `catalog.json`

## Доступ для коллег (локальная сеть)

Когда понадобится открыть доступ:
1. Узнай IP своей машины: `ipconfig` → IPv4 Address (например `192.168.1.50`)
2. Коллеги открывают в браузере: `http://192.168.1.50:5000`
3. Ничего устанавливать им не нужно
